description: Write a handoff note for the current issue before starting a fresh session
disable-model-invocation: true
---

Wrap up this session so the next one can start from a clean context.

1. Find the issue this session worked on (from the branch name, the PR, or the conversation). If unclear, ask.
2. Write a short handoff note: what is done (with commit or PR links), what is left, decisions made and why, and any out-of-scope findings worth their own issue.
3. Post it as a comment on the issue with `gh issue comment`. Show me the text first and wait for my OK.
4. Offer to open new issues for the out-of-scope findings.
5. End by saying the session can be cleared with `/clear`.
