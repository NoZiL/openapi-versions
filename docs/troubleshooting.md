# Troubleshooting

| Symptom                                                                                       | Cause                                                                                                                                            | Fix                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Breaking-change gate cannot run: oasdiff not found` (or `WARN breaking-change gate skipped`) | oasdiff not on `PATH`, or older than 1.34.0                                                                                                      | Install it (`brew install oasdiff`) or set `OASDIFF_BIN=/abs/path/oasdiff`. The error only appears with `"gate": "required"`, `--require-gate` or `--check-only`; otherwise codegen warns and continues |
| `Floor 1.3.0 has no spec file (oldest found: 1.4.0)`                                          | The floor needs its own `specs/1.3.0.json`                                                                                                       | Add the spec or lower/raise the floor to an existing one                                                                                                                                                |
| `No spec found for major 1 at or above floor 1.3.0`                                           | Wrong `specsDir`, or files not named `<semver>.json`                                                                                             | Check the directory and file names; non-semver names are ignored                                                                                                                                        |
| `config: majors.1.floor 2.0.0 is not in major 1`                                              | Floor belongs to another major                                                                                                                   | Fix the floor or the major key                                                                                                                                                                          |
| `FAIL v1: a -> b`                                                                             | A spec pair is not additive                                                                                                                      | [How-to: breaking-change failure](how-to.md#handle-a-breaking-change-failure)                                                                                                                           |
| oasdiff reports `response-property-enum-value-added`                                          | A closed `enum` gained a value                                                                                                                   | Declare it `x-extensible-enum` (see how-to) or move it to a new major                                                                                                                                   |
| Calling a newer operation through `$api` does not compile                                     | By design: it exists only on `$gated`                                                                                                            | Use `$gated` with `gate()` or `<Feature>`                                                                                                                                                               |
| `useSuspenseQuery(gate(...))` does not compile                                                | A gated query may be skipped                                                                                                                     | Use `useQuery`                                                                                                                                                                                          |
| Enum type collapses to `string` and loses autocompletion in response data                     | `openapi-fetch`'s `Readable<T>` maps over `string & {}`                                                                                          | Apply the one-line patch in `patches/` to `openapi-typescript-helpers` with `patch-package` (add `"postinstall": "patch-package"` to your app). Until it is fixed upstream                              |
| App says "app too old" for a date-style version such as `2026.10.1`                           | Valid semver with major 2026                                                                                                                     | The backend must report real `major.minor.patch`                                                                                                                                                        |
| `GET /version failed: 404`                                                                    | `/version` resolved from the host root                                                                                                           | `baseUrl` must include the major prefix; `/version` is read relative to it (`https://host/api/v1/version`)                                                                                              |
| Endless refetching after a deploy                                                             | Version header seen again before React re-rendered                                                                                               | The provider records the new version synchronously; do not clone this logic without that                                                                                                                |
| Staging on `1.6.0-rc.1` hides 1.6 features                                                    | A prerelease sorts before its release                                                                                                            | Pass `prereleaseAsRelease` to `ApiVersionProvider` / `createApi` for staging builds                                                                                                                     |
| A gated field is `undefined` on a new backend                                                 | Fields added after the floor are typed optional and may be absent                                                                                | Use `hasField()` and handle absence                                                                                                                                                                     |
| `src/generated` missing, imports fail                                                         | Codegen not run                                                                                                                                  | `pnpm codegen`                                                                                                                                                                                       |
| `Cannot read properties of undefined (reading 'createKeywordTypeNode')` when generating       | openapi-typescript 7 needs the TypeScript 5 or 6 JS compiler API; TypeScript 7 (native, now `latest` on npm) does not expose it (upstream #2841) | Install `typescript@<7` (5 or 6)                                                                                                                                                                        |
| `Cannot find module 'openapi-versions'` from a generated `client.ts`                          | Runtime not installed, or `runtimeImport` wrong                                                                                                  | `npm i openapi-versions`, or set `runtimeImport` in the config                                                                                                                                          |
